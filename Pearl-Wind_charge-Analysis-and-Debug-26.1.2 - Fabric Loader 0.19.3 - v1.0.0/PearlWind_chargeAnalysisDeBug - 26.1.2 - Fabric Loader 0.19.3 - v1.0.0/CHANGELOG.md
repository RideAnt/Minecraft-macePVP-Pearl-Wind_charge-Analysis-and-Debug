# Changelog

## 1.0.0

- Finalized the singleplayer testing scope and public documentation.
- Added P1/P2 camera locking through the main mod's read-only target provider.
- Added deterministic projectile-spread testing on the integrated singleplayer server.
- Added optional diagnostic logging.
- Kept every Debug feature disabled by default.
- Kept the main-mod dependency version unrestricted.
- Declared incompatibility with the old ProjectileAccuracyTest mod.
- Removed the legacy icon namespace and unused Maven publishing configuration.

## 1.0.0

- First formal Debug companion release.
- Separated automatic camera locking and projectile-spread testing from the main mod.
- Added migration support for legacy Debug configuration values.
